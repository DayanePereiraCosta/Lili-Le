**Toda grande aventura começa com uma descoberta. E toda descoberta pode começar com uma palavra!** 💜

Lili Lê é um projeto de aplicativo infantil que nasceu da ideia de transformar o início da alfabetização em uma experiência divertida, mágica e interativa.

Acompanhada por Lili Lê, uma pequena criatura mágica e exploradora, a criança será convidada a descobrir sílabas, formar palavras e explorar o encantador universo da leitura.

Mais do que aprender, a proposta é despertar a curiosidade, estimular a autonomia e fazer com que cada pequena conquista seja motivo de comemoração! 🌈

---

## 🧚 Conheça a Lili Lê

Lili Lê é nossa companheira de aventuras!

Curiosa, divertida e apaixonada por descobertas, ela acompanha as crianças durante a jornada de aprendizagem, incentivando cada nova tentativa e celebrando cada conquista.

Sua missão é mostrar que aprender a ler também pode ser uma grande aventura!

## 🌟 O que estamos construindo?

A proposta do aplicativo inclui:

- 🔤 **Descoberta das sílabas:** atividades interativas para explorar combinações silábicas.
- 📖 **Primeiras palavras:** experiências para desenvolver o reconhecimento e a formação de palavras.
- 🎮 **Aprendizagem lúdica:** atividades que transformam o aprendizado em brincadeira.
- 🧚 **Uma companheira de aventuras:** Lili Lê acompanha e incentiva a criança durante a jornada.
- 🎨 **Experiência visual encantadora:** um universo colorido, acolhedor e pensado para o público infantil.

## 🛠️ Tecnologias utilizadas

O projeto está sendo desenvolvido com:

- React Native
- Expo
- TypeScript
- Expo Router

## 💻 Executando o projeto

Quer conhecer o projeto ou acompanhar seu desenvolvimento?

**1. Clone o repositório:**

```bash
git clone https://github.com/DayanePereiraCosta/Lili-Le.git
```

**2. Entre na pasta do projeto:**

```bash
cd Lili-Le
```

**3. Instale as dependências:**

```bash
npm install
```

**4. Inicie o Expo:**

```bash
npx expo start
```

Para testar no navegador:

```bash
npx expo start --web
```
